# Tensegrity-Based Strain Sensor

MATLAB code and experimental data for the paper

> **Design and Characterization of a Tensegrity-Based Strain Sensor for Large Deformations**
> Yunjeong Kim, Nasu Kim, Namjung Kim

This repository contains the full pipeline from raw experimental data to the
figures reported in the paper: hyperelastic characterization of the string
material, equilibrium analysis of the tensegrity structure under compression,
and force estimation from resistance measurements of the conductive strings.

## Requirements

- MATLAB R2021a or later
- Optimization Toolbox (`fminunc`, `fsolve`)
- Signal Processing Toolbox (`sgolayfilt`, `butter`, `filtfilt`, `medfilt1`)

No external MATLAB packages are required.

## How to reproduce

Run the scripts in the following order. Each step writes its output into
`data/processed/`, which the next step consumes.

**1. Material characterization**

```matlab
cd src/material_characterization
generate_stress_interp     % string_stress_interp.mat
fit_mooney_rivlin          % mooney_constants.mat   (C1, C2)
```

**2. Build the tensegrity model**

```matlab
cd src/tensegrity_model
build_tensegrity_model     % tensegrity_sensor_model.mat
```

**3. Compression simulation (PVW)**

```matlab
cd src/simulation
run_compression_simulation % string/bar force logs, summary_log.txt
```

**4. Force estimation from resistance**

```matlab
cd src/sensor_estimation
estimate_force_from_resistance   % Figures comparing PVW vs ΔR-based force
```

**5. Paper figures**

```matlab
cd figures
plot_UTM_load_strain
plot_mooney_fit_low_strain
```

---

## Notes

- All scripts use SI units (meters, Newtons, Pascals).
- File paths inside scripts are written as if MATLAB's working directory is the
  script's own folder. Add `data/` and `src/utils/` to the path, or `cd` into
  the script folder before running.
- Pre-computed `.mat` files are included under `data/processed/` so that any
  single step can be run independently without re-running the previous ones.
